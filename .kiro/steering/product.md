# Product Overview

GoldFlux is a production-grade Gold Price Prediction web application. It aggregates historical gold market data (GC=F ticker), trains machine learning models to forecast future prices, and presents predictions alongside historical trends on an interactive dashboard.

## Value Proposition

- Automated daily data ingestion from financial markets
- ML-powered 30-day gold price forecasts with confidence intervals
- Interactive visualization of historical and predicted price data
- Model performance transparency via accuracy metrics
